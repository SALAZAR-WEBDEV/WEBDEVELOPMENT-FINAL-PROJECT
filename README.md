# Holy Grounds - Campus Life Super App

### Description
A responsive web application for Holy Grounds coffee shop at Oakland City University. This project provides students with a digital menu, location info, and a fun interactive coffee surprise feature.

### Technologies Used
* HTML5 (Semantic Structure)
* CSS3 (Custom Styling & Media Queries)
* Bootstrap 5 (Responsive Layout)
* JavaScript (ES6+)
* Giphy API (External API Integration)

### Features
* **March Specials:** Visual cards for seasonal drinks with full images.
* **Full Digital Menu:** Detailed pricing for coffee, tea, and frappes.
* **Interactive Coffee Surprise:** Uses the Giphy API to fetch coffee-themed animations.
* **Info & Hours:** Mobile-responsive table showing specific shift hours and location.

### Future Improvements
* Integration of an online ordering system.
* A "Loyalty Rewards" tracker for frequent students.
